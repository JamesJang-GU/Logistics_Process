# Logistics_Process

한국의 수출입물류 프로세스(해상·항공 수출/수입)를 애니메이션으로 보여주는 단일 HTML 페이지입니다.

- 파일: [`index.html`](index.html) — 브라우저로 열면 바로 실행됩니다 (외부 의존성은 Google Fonts뿐).
- 탭: 해상 수출 · 해상 수입 · 항공 수출 · 항공 수입 (해상은 FCL / LCL 전환)
- 단계 카드나 장면 속 시설에 마우스를 올리면 해설이 표시됩니다.
- 재생 / 이전 / 다음 / 처음 버튼과 속도 조절, 단계 카드 클릭으로 이동
- 딥링크: `index.html#seaIm/FCL/5` 형식으로 특정 탭·단계를 바로 열 수 있습니다.
