# Logistics_Process

한국의 수출입물류 프로세스(해상·항공 수출/수입)를 한 화면에서 보여주는 HTML 페이지입니다. 외부 의존성은 Google Fonts뿐이며 브라우저로 열면 바로 실행됩니다.

## 페이지

| 파일 | 내용 |
|---|---|
| [`index.html`](index.html) | **Process Map** — 좌측 순서도(서류 / 화물 2열) + 상단 서류 라인 + 3D 화물 흐름 장면 |
| [`animation.html`](animation.html) | 이전 버전 — 단계 카드 + 애니메이션 장면 |

## Process Map 사용법

- 탭: 해상 수출 · 해상 수입 · 항공 수출 · 항공 수입 (해상은 FCL / LCL 전환)
- 좌측 순서도: 파란 열 = 서류·신고, 주황 열 = 화물 이동·현장 작업. 박스를 클릭하면 해당 단계로 이동
- 우측 상단: 서류가 당사자 사이를 '서류 라인' 한 줄로 이동
- 우측 하단: 트럭·철도·크레인·선박·ULD·항공기가 3D로 이동, 단계별 경로와 번호, 현재 화물 위치 핀 표시
- 재생 / 이전 / 다음 / 처음 버튼과 속도 조절
- 박스·당사자·시설에 마우스를 올리면 해설 표시
- 딥링크: `index.html#seaIm/FCL/5` 형식으로 특정 탭·단계를 바로 열 수 있습니다.
